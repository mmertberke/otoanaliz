# Otoanaliz

## Çalıştırma

Klasörü VS Code ile açın. index.html dosyasına sağ tıklayıp Open with Live Server seçeneğine basın.

## İlk hafta

HTML ile ana sayfa, araçlar ve hakkında sayfaları hazırlandı. Sayfalar arasına bağlantılar ve üç örnek araçtan oluşan bir tablo eklendi. Tablodaki yıl ve kilometre değerleri örnektir.

- index.html: Ana sayfa
- araclar.html: Araç tablosu
- hakkinda.html: Proje hakkında

## İkinci hafta

Araç tablosundaki örnek yıl ve kilometreler kaldırıldı. Marka, model, motor ve inceleme bilgileri eklendi.

- inceleme.html: Clio için inceleme taslağı ve genel kontrol listesi
- notlar.html: Araç seçimi, başlık ve not alanlarından oluşan form

Beş sayfaya da ortak menü eklendi. İncelemedeki güçlü ve zayıf yön başlıkları henüz araştırma aşamasında. Form not kaydetmez; Kaydet düğmesi işlevsizdir. JavaScript kullanılmadı, mevcut CSS değiştirilmedi.
