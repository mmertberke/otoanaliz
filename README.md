# Otoanaliz

## Çalıştırma

Klasörü VS Code ile açın. index.html dosyasına sağ tıklayıp Open with Live Server seçeneğine basın.

## İlk hafta

HTML ile ana sayfa, araçlar ve hakkında sayfaları hazırlandı. Sayfalar arasına bağlantılar ve üç örnek araçtan oluşan bir tablo eklendi. Tablodaki yıl ve kilometre değerleri örnektir.

- index.html: Ana sayfa
- araclar.html: Araç tablosu
- hakkinda.html: Proje hakkında
